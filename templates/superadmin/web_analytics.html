Setup Guide

1. Google Analytics 4

  1. Go to analytics.google.com
  2. Create a Web property → copy the Measurement ID (G-XXXXXXXXXX)
  3. Paste it above and save — GA4 tracking activates immediately

2. Google Search Console

  1. Go to Search Console → Add property
  2. Choose "URL prefix" → enter your domain
  3. Select HTML meta tag verification → copy the content value
  4. Paste it in the GSC field above and save
  5. Click Verify in Search Console — then submit your sitemap URL

3. Submit Sitemap

In Search Console → Sitemaps → Add: {{ google.sitemap_url }}
