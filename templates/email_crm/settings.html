Resend requires a verified sending domain
  1. Go to resend.com/domains and add your domain (e.g. lawcolab.com).

Resend Setup Guide

Step-by-step for Resend:

  1. Sign up at resend.com
  2. Go to API Keys → create a key
  3. Copy the key (starts with re_)
  4. Add it as RESEND_API_KEY in Railway environment variables or paste it in the API Key field above
  5. Go to Domains → add lawcolab.com
  6. Add the DNS records to your domain registrar
  7. After DNS propagates (<48h), click Verify
  8. Set From Email to any address on the verified domain
  9. Click Save Settings then Send Test Email
⚡ Quick test (no domain needed):
Set From Email to onboarding@resend.dev — works instantly for testing.

Security

The recommended approach is to set RESEND_API_KEY as a Railway environment variable — the app reads it automatically and you never need to paste it here.

If you paste the key in the form above, it is stored in the database. Leave it blank on subsequent saves to keep the existing stored key.
