Replit Prompt — Build the LAWCOLAB Super Admin Email CRM

You are a senior SaaS architect and full-stack engineer. Upgrade the existing LAWCOLAB application by implementing a production-ready Email CRM for the Super Admin Dashboard. The system must feel comparable to HubSpot, Salesforce, and Pipedrive while maintaining LAWCOLAB's branding and clean user experience.

Objective

Create a centralized email communication hub that enables the LAWCOLAB Super Admin to send, receive, track, organize, and automate email communications with every law firm discovered by the crawler and every law firm registered on the platform.

The email system must integrate seamlessly with the existing CRM, Law Firm Directory, AI Lead Discovery module, and user management system.

• Registered LAWCOLAB customers

• Crawled law firms from the Law Firm Directory

Merge both into a unified CRM.

If duplicates exist, merge intelligently using:

- Firm Name similarity

Never create duplicate companies.
